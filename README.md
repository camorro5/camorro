# Infinix Smart 4 - Telegram RAT Tool

أداة اختبار اختراق لجهاز Infinix Smart 4 تعمل عبر Telegram Bot كـ C2.
تحول سكربت Python إلى APK يثبت على جهاز الهدف ويتم التحكم به عن بعد.

## ⚠️ إخلاء مسؤولية
للأغراض التعليمية واختبارات الاختراق المصرح بها فقط.

## الميزات
- Shell كامل على جهاز الهدف
- تصوير كاميرا (أمامية + خلفية)
- لقطة شاشة - تحديد GPS - سحب جهات الاتصال
- سحب SMS - استخراج واتساب كامل
- Keylogger - سحب أي ملف - رفع ملفات للجهاز
- Persistence بعد إعادة التشغيل - إخفاء أيقونة التطبيق
